# Токен Яндекс Музыки

Нужен аккаунт с Плюсом: без подписки Яндекс отдаёт только 30-секундные
отрывки, и bridge от таких треков отказывается. Лучше отдельный аккаунт,
а не личный: официального API нет, и за неофициальный доступ Яндекс может
заблокировать аккаунт.

1. Открыть в браузере, где выполнен вход в нужный аккаунт (лучше в
   приватном окне, войдя только в него):
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`
   (это client_id официального приложения Яндекс Музыки).
2. Разрешить доступ. Браузер перейдёт на адрес вида
   `https://music.yandex.ru/#access_token=<ТОКЕН>&...` — нужна часть между
   `access_token=` и `&`.
   Токен выглядит как длинная строка из букв и цифр, часто начинается с `y0_`.
3. Вписать в `YANDEX_TOKEN=` в `.env` bridge и перезапустить его. На servnnik:

   ```bash
   cd ~/minecraft/syrradio-bridge
   nano .env                # строка YANDEX_TOKEN=<токен>
   docker compose up -d
   ```

4. Проверить: `/health` показывает `yandex` с `enabled: true`:

   ```bash
   docker exec mc-server-tfgm-1 curl -s http://syrradio-bridge:8080/health
   ```

5. Добавить в игре ссылку на трек вида `https://music.yandex.ru/album/…/track/…`.

Если адрес из шага 1 перестал работать (Яндекс меняет вход), актуальные
способы получить токен — в документации библиотеки
[yandex-music](https://github.com/MarshalX/yandex-music-api).

Отозвать токен — выйти на всех устройствах в настройках аккаунта Яндекса
(id.yandex.ru → «Безопасность»).

Токен даёт полный доступ к аккаунту Яндекс Музыки — никому не показывать и
в git не класть.

Bridge качает по одному треку по мере надобности и не копит медиатеку
(файлы живут в кэше час).

Отметки о прослушивании по умолчанию выключены: на личном аккаунте в
историю и «Мою волну» попадали бы треки, которые ставят другие игроки.
На отдельном аккаунте для радио их можно включить — `YANDEX_REPORT_PLAYS=true`
в `.env` и `docker compose up -d`.

Правила Яндекс Музыки и авторские права соблюдает тот, кто запускает сервер
со своим аккаунтом, — см. Disclaimer в [../../README.md](../../README.md).
