# Пакеты и совместимость

Код: `net/`.

Канал `syrradio:main` принимает любую версию и отсутствие мода с любой
стороны: игрок без мода заходит на сервер, игрок с модом — на сервер без мода.
В `mods.toml` стоит `displayTest="IGNORE_ALL_VERSION"`, чтобы список серверов
не помечал такой сервер как несовместимый.

Версию сверяем сами, пакетом `HelloPacket`:

1. Сервер при входе игрока с модом шлёт `Hello(PROTOCOL)`.
2. Клиент отвечает своим `Hello`.
3. Совпали — дальше ходят остальные пакеты. Не совпали — радио у игрока
   молчит, экран просит обновить мод, сервер пишет ему в чат ссылку.

Формат `HelloPacket` заморожен навсегда: один varint под номером 0.

| Пакет | Куда | Что |
|-------|------|-----|
| `HelloPacket` | ⇄ | версия протокола |
| `StatePacket` | → клиенту | весь список, курсор, позиция, пауза, режимы, `serial`, следующий трек |
| `ChunkPacket` | → клиенту | кусок ogg-файла |
| `NoticePacket` | → клиенту | короткое сообщение («добавлено», ошибка) |
| `AddPacket` | → серверу | ссылка |
| `ControlPacket` | → серверу | назад, вперёд, пауза, повтор, перемешать, включить, очистить |
| `RemovePacket` | → серверу | убрать трек |
| `MovePacket` | → серверу | перетащить трек |
| `SeekPacket` | → серверу | перемотать |
| `ListeningPacket` | → серверу | слушаю / не слушаю (громкость 0) |

«Вперёд», «назад» и перемотка несут id трека, на который смотрел игрок:
двойное нажатие не перелистнёт два трека.

Игроку без мода сервер через 5 секунд после входа пишет в чат
`joinMessages.missingMod` со ссылкой `downloadUrl`, игроку со старым
протоколом — `joinMessages.outdatedMod`.

Любое изменение пакетов, кроме `HelloPacket`, — новая версия протокола
([../contributing/versioning.md](../contributing/versioning.md)).
