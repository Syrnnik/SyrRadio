# Как вести документацию

- В корне — только README: описание мода для игроков и админов, по-английски.
- Всё остальное — в `docs/`, по-русски. Раздел — папка, тема — файл. Файл
  про одну вещь и короткий: вырос за 80 строк — делить.
- Новый файл — сразу строчка в [../README.md](../README.md).
- Поменяли поведение — поправить документ в том же коммите.
- Писать то, что проверено по коду. Не знаете — не пишите.
- Секретов (токены, пароли) в документации не бывает: только где они лежат.
