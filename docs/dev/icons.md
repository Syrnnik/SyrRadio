# Иконки плеера

`mod/src/main/resources/assets/syrradio/textures/gui/icons.png` — полоса
иконок 16×16, белые на прозрачном фоне: перемешать, назад, играть, пауза,
вперёд, повтор, повтор трека, удалить, включить. Цвет (подсветка
включённого режима, серость неактивной кнопки) задаётся в игре.

Рисует их скрипт (нужен Pillow):

```bash
python3 mod/tools/make_icons.py
```

Поменять иконку — поправить скрипт и запустить заново. Порядок иконок
совпадает с константами `ICON_*` в `RadioScreen`.
